RE.LOG HOMEPAGE REFINEMENT BUILD
Based on Build 09.3.

Changes:
- Added a subtle fixed viewport frame to evoke a contained terminal/screen interface.
- Reworked homepage editorial cards into clickable Field Notes with meaningful destinations and clear calls to action.
- Renamed the secondary image-led collection to The Cabinet and upgraded its cards with hover treatments and captions.
- Rebuilt Oliver's client-side interaction lifecycle: first-contact state is only marked complete when the visitor enters the workspace; refresh before completion resumes the introduction; completed first-contact does not replay.

BUILD 11 — CMS CONTENT + IDENTITY REFRESH
=========================================
- Added a shared server-side content loader at content/index.ts. It reads Pages CMS Markdown files from content/logs, content/articles and content/materials.
- Published Logs are assembled by issue_number. Published articles are associated through parent_issue_number. Log article_slugs controls display order when supplied; otherwise matching articles are listed by file order.
- Published supplementary material is read from content/materials and attached by parent_article or parent_issue_number.
- Homepage, archive, experiments, library and transmission reader now use CMS-backed content rather than content/editions.ts.
- Oliver receives the published transmission index from the server layout and uses it for /latest and /random.
- Added a reusable four-corner / phosphor-eye SignalMark component for the Re.Log brand and Oliver interface.
- Updated the design palette to near-black, warm ivory, olive and phosphor green. Headings now use Space Grotesk, body copy DM Sans, and system labels IBM Plex Mono. The wordmark is Re.Log with one period.
- Added `gray-matter` and `marked` dependencies for CMS frontmatter and Markdown rendering.
- Corrected Pages CMS relationship field labels to use parent_issue_number.
- Removed the stale nested relog-website copy from the repository ZIP to avoid two competing project roots.
